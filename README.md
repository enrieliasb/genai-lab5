# Smurfit Westrock Sustainability Guide

Static website for an SMU Cox MBA course assignment (GenAI for Business). It presents a student-built concept: a customer-facing guide to Smurfit Westrock’s published sustainability approach, with the class Chatling conversation available on the page.

This is an independent student prototype. It is not an official Smurfit Westrock website.

**Live site:** https://enrieliasb.github.io/genai-lab5/

Open `index.html` for the landing page and `about.html` for the concept. The chat panel needs a network connection. Everything else is plain HTML, CSS, and JavaScript and works from the repository root.

Display type is [Fraunces](https://github.com/undercasetype/Fraunces) and [Outfit](https://github.com/Outfitio/Outfit-Fonts), both under the SIL Open Font License. License texts are in `assets/fonts/`.
